# 今日小馆设计

为纸张老黄历增加每天可回访的轻量玩法：每日抽签、生活小挑战和盖章集册。保持原有翻页、撕纸和导出体验。

## 玩法

- 每日签：从「随心、专注、松弛、相聚」中选一个主题。日期与主题决定签文，刷新、重新打开或重新抽取都得到同一签；翻到另一日可以查看那天的签。
- 小挑战：同一日期对应一个具体、低门槛的小行动；只允许对上海时区的今天盖章，每天只能记一次。
- 集章册：显示总章数、连续天数与最近七天的印章。重复点击不累计，历史日期只能查看。
- 分享签文：优先复制到剪贴板；不可用时提供可手动复制的文本。

## 界面与架构

新增「今日小馆」工具按钮和黄历下方的文字入口。展开纸色面板，以签筒、竖排签诗和朱砂印章为视觉重点；手机上可滚动，支持键盘关闭、可见焦点和减少动态效果偏好。

纯 JavaScript 玩法逻辑置于 daily-play.js，界面置于 daily-play-ui.js / daily-play.css。日历通过自定义事件通知当前日期，UI 不访问渲染器私有状态。记录只保存在本浏览器 localStorage；无账号、无后端。存储不可用时可继续体验，并明确提示记录仅在当前页面保留。

## 验证

Node 内置测试验证固定每日结果、日期校验、今天限制、重复盖章、跨月/跨年连续记录及损坏数据容错。Playwright 检查真实页面的抽签、切换主题、刷新恢复、历史日期限制、面板互斥、键盘操作和手机布局。浏览器截图人工检查纸张排版。
