# 老黄历 · 纸上光阴

可翻页、可撕纸的电子老黄历，支持 1900—2099 年的日期跳转与日历导出。

## 今日小馆

点击日历下方「今日小馆」，或右侧签筒图标，也可以按 `G` 打开。

- **每日一签**：选择随心、专注、松弛或相聚，轻摇签筒，展开一张生活签。包含 24 张原创签文；同一天、同一心情的结果固定，刷新也不会改变。翻页可以查看其他日期的签。
- **生活小挑战**：每天一个 2—5 分钟的小行动。完成后盖一枚朱砂章，每天只能记录一次；历史和未来日期只能查看，可以点击「回到今天」继续。
- **小欢喜集章册**：查看总章数、连续天数与最近七天的记录。今天尚未盖章时保留昨天的连续天数，错过整天后归零。
- **分享签文**：点击「复制签文」分享；浏览器不允许自动复制时，提供可手动复制的文本。

盖章按上海时区计算。记录保存在当前浏览器的 `localStorage`，清除站点数据后会消失，不会跨设备同步；存储不可用时，页面会提示记录仅在当前页面保留。签文是原创生活灵感，独立于日历中的传统宜忌。

## 本地运行

无需构建或安装 npm 依赖。请通过 HTTP 服务打开，让字体与日历模板正常加载：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765>。

键盘操作：`←` 前一天、`→` / 空格 后一天、`T` 撕纸、`R` 回到今天、`E` 导出、`G` 今日小馆、`Escape` 关闭面板。纸张翻页快捷键在日历获得焦点时使用。

## 验证

玩法规则使用 Node 内置测试：

```sh
node --test tests/daily-play.test.cjs
```

浏览器流程测试需要 Python Playwright 和 Chromium，并先启动上述本地服务：

```sh
pip install playwright
python -m playwright install chromium
python tests/browser-smoke.py
```

浏览器测试覆盖桌面与手机的抽签、主题选择、盖章、刷新恢复、真实日期翻页、原有工具面板、键盘焦点，以及复制和存储失败的降级体验。截图输出至 `test-results/`。
